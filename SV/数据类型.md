# 数据类型

## 2.1 内建数据类型

- 四值类型：可表示0,1,X,Z，更贴近硬件，但是比二状态多占用1倍空间

  wire：连续赋值

  reg：  过程赋值

  logic：大多情况下可以代替reg和wire直接使用，双向信号除外

  integer：32位有符号整数

  time： 64位无符号整数

> 使用系统函数`$isunknown()`判断任意位是否出现X或Z，是则返回1.

---

- 二值类型：仅表示 **0 和 1** 两种逻辑状态

    bit：1位，无符号，默认初始值为0
    
    byte: 8位，有符号整数

    shortint: 16位，有符号

    int：32位，有符号

    longint：64位，有符号   

    real：64位，双精度浮点数



## 2.2 定宽数组/静态数组

- 声明

  verilog中要求数组必须给出上下界；

  SV中默认使用0作为索引下界，因此允许只给出数组宽度，格式如下：

  ```verilog
  int arr1[0：15];
  int arr2[16];
  ```



- 越界访问

  二值状态如int、bit，默认返回0；

  四值状态如logic，默认返回X；

  线网在无驱动时，返回Z；



- SV仿真器存放数组元素的字边界：32bits

  非合并数组，字的低位用于存放数据，高位不使用，如：

  ```verilog
  bit [7:0] b_unpack[3]; //只是用了低8位存储空间
  ```

  

- 数据初始化：单引号 + 大括号

  ```verilog
  int arr1[4] = '{0,1,2,3};
  int arr2[5];
  arr2 = '{9,8,default:1}; //使用default指定缺省值
  ```
  
  

- 基本操作

  - 最常见：for和foreach

  ```verilog
  for(int i=0;i<$size(src);i++) stc[i]=i;
  
  foreach(dst[j]) dst[j]=src[j]*2;
  ```

  

  `$size`：返回数组的宽度

  foreach遍历多维数组的差异：

  ```verilog
  int md[2][3]='{'{0,1,2},'{3,4,5}};
  initial begin
      foreach(md[i,j]) $display("md[%0d][%0d]=%0d",i,j,md[i][j]);
  end
  ```

  ---

  - 复制和比较（聚合操作，即整个数组一起，而不是单个元素）

    比较只限于等于或不等于比较；



- 合并数组

  存放方式：连续存放，中间无任何闲置空间

  ```verilog
  bit [3:0][7:0] bytes; //4个字节组成32bits数据，存放位置连续
  
  bit [3:0][7:0] barr[3]; //3个类似bytes元素的数组，存放不连续
  ```

  

## 2.3 动态数组

- 声明：空下标[]

  使用**`new[]`**操作符分配空间

  ```verilog
  int dyn[],d2[];
  initial begin
      dyn=new[5];
      foreach(dyn[i]) dyn[i]=i;
      d2=dyn;				//分配空间，并复制
      dyn=new[20](dyn); 	//分配20个整数值并进行复制，释放原来的5个元素空间
      dyn=new[100];		//分配100个元素空间，并释放原来20个元素空间
      dyn.delete();		//删除数组
  end
  ```

- 初始化

  可以使用动态数组保存元素个数不定的数据

  ```verilog
  bit[7:0] mask[]='{8'h01, 8'h02};
  ```

  

- 只要数据类型相同，动态数组和静态数组之间可以相互赋值

  元素数目相同：可以把动态数组赋值给静态数组；

  静态数组赋值给动态数组过程：先调用构造函数new[]分配空间，再进行赋值。



## 2.4 队列

- 声明：[$]

- 初始化：和数组不同，不需要单引号，只需要大括号{}

  不能对队列使用构造函数new[]，当元素超过原有空间，SV会自动分配更多空间；

  ```verilog
  int q[$]={0,2,5};
  ```

- 操作

  - 插入：`q.insert(i,j)`，在位置i处插入元素j；

    队列前插入：`q.push_front(j)`；

    队列末尾插入：`q.push_back(j)`；

  - 删除

    `q.pop_front`：删除第一个元素

    `q.pop_back`：删除末尾元素

    `q.delete()`：删除队列

    `q=q[1:$]`：删除第一个元素

    `q=q[0:$-1]`：删除末尾元素

    `q={}`：删除队列

## 2.5 关联数组

- 用途：存储稀疏矩阵元素



- 声明、初始化

  ```verilog
  int switch[string],min_addr,max_addr;
  initial begin
      int i,r,file;
      string s;
      file=$fopen("switch.txt", r);
      while(!$feof(file))begin
          r=$fscanf(file, "%d %s",i,s);
          switch[s]=i;
      end
      $fclose(file);
      //获取最小地址值，缺省为0；
      min_addr=switch["min_addr"];
      //获取最大地址值，缺省为1000；
      if(switch.exists("max_addr"))
          max_addr=switch["max_addr"];
      else max_addr=1000;
      
      foreach(switch[s])
          $display("switch['%s']=%0d", s, switch[s]);
  end
  ```

  

## 2.6 数组方法

- 数组计算（缩减）方法

  sum求和

  product积

  and与

  or或

  xor异或



- 查找/定位方法

  min()：返回最小值队列

  max()：返回最大值队列

  unique()：返回数组中具有唯一值的队列

  ```verilog
  int f[6]='{1,6,2,6,8,6}; //数组
  int d[]='{2,4,6,8,10}; //动态数组
  int q[$]={1,3,5,7},tq[$]; //队列
  
  tq=q.min(); //{1}
  tq=d.max(); //{10}
  tq=f.unique(); //{1,6,2,8}
  ```

  find：

  ```verilog
  int d[]='{9,1,8,3,4,4},tq[$];
  tq=d.find with (item>3); //item：内置默认变量名，代表单独元素，缺省名字
  tq=d.find(x) with (x>3); // 指定别的名字
  //等效代码
  tq.delete();
  foreach(d[i]) if(d[i]>3) tq.push_bck(d[i]);
  
  tq=d.find_index with (item>3); //大于3元素对应的索引值{0,2,4,5}
  tq=d.find_first with (item>99); //{},返回空队列，从前往后搜索
  tq=d.find_first_index with (item==8); //{2} d[2]=8
  tq=d.find_last with (item==4); //{4} 从后往前搜索
  tq=d.find_last_index with (item==4); //{5} d[5]=4
  ```

> 返回的队列是int类型，而不是Integer。



- 计算方法与with结合使用

  与find with不同，返回的是1（真）或0（假）

  ```verilog
  int count,total,d[]=`{9,1,8,3,4,4};
  count=d.sum with (item>7); //2 统计大于7的元素个数
  total=d.sum with ((item>7)*item); // 大于7的元素求和 9+8
  total=d.sum with (item<8?item:0); // 小于8的元素求和
  count=d.sum with (item==4); // 2 等于4的元素个数
  ```

  

- 排序

  reverse()：反转

  sort()：从小到大排序

  rsort()：从大到小排序

  shuffle()：打乱顺序

  其中，reverse和shuffle作用范围是整个数组，不能带with条件



## 2.7 typedef创建新类型

- 旧的定义方法define

  ```verilog
  `define OPSIZE 8
  `define OPREG reg[`OPSIZE-1:0]
  `OPREG op_a,op_b;
  ```

  本质：没有创建新的类型，只是进行文本替换。



- 用户自定义类型

  ```verilog
  parameter OPSIZE=8;
  typedef reg[OPSIZE-1:0] opreg_t;
  
  typedef bit[31:0] uint; //32bits双状态无符号数
  typedef int unsigned uint; //等价
  ```

  

## 2.8 struct结构体

- struct功能比class类少

  class：和verilog中的module一样，可包含数据和程序（always/initial代码块及子程序），不可综合，多用于仿真验证；

  结构体struct：把数据组织到一起，声明时立即分配静态内存，可综合



- 创建和初始化

  ```verilog
  initial begin
      typedef struct {int a;
                     byte b;
                     shortint c;
                      int d;} mystrcut_s;
      mystrcut_s st='{32'haaaa_aaaa, 8'hbb, 16'hcccc, 32'hdddd_dddd};
      $display("str=%x %x %x %X", st.a,st.b,st.c,st.d);
  end
  ```

  

- 合并结构体：结构体数据连续存放，中间无闲置空间

  ```verilog
  typedef struct packed {bit [7:0] r,g,b;} pixel_p_s;
  ```



## 2.9 枚举类型

枚举类型：可自动为列表中的每个名称分配不同的数值，默认为int型

- 声明：

常量名称列表 + 一个或多个变量

```verilog
enum {RED, BLUE, GREEN} color;
```



带署名的枚举类型

```verilog
typedef enmu {INIT,DECODE,IDLE} fsm_e;
fsm_e pstate,nstate; //声明变量
initial begin
    case(pstate)
        IDLE: nstate=INIT;
        INIT: nstate=DECODE;
        default: nstate=IDLE;
    endcase
    $display("Next state os %s", nstate.name()); //显示状态符号名
end
```



- 定义枚举值：缺省时，从0开始递增的整数；可以自己定义。

```verilog
// INIT-0 DECODE-2 IDLE-3
typedef enmu {INIT,DECODE=2,IDLE} fsm_e;
```



- 枚举类型子程序

  1、first()：返回第一个枚举常量；

  2、last()：返回最后一个枚举常量；

  3、next()：返回下一个枚举常量；

  4、next(N)：返回之后第N个枚举常量；

  5、prev()：返回前一个枚举常量；

  6、prev(N)：返回以前第N个枚举常量

  注意：当到达枚举常量列表的头或者尾时，函数next和prev会自动以**环形方式**绕回

  





## 2.10 类型转换

- 静态转换

  不对转换值检查；

  转换时，指定目标类型，并加上单引号即可

  ```verilog
  int i;
  real r;
  i=int'(10.0-0.1);
  r=real'(42);
  ```



- 动态转换

  转换函数：`$cast`

  允许对越界的数值进行检查

  转换成功，返回1；否则返回0，且SV会打出错误信息



- 流操作符

  `>>`：把数据从左至右变成流；

  `<<`：把数据从右至左变成流；



## 2.11 字符串

常见操作：

- getc(N)：返回位置N上的字节
- toupper：返回一个所有字符大写的字符串；
- tolower：返回一个小写的字符串；
- {}：可用于串接字符串；
- substr(start,end)：提取出从位置start到end之间的所有字符
