# 2. SV中的随机化

SV的随机化通常和类一起使用

随机化方式：

- rand：标准均匀分布
- randc：周期性随机。遍历完取值范围内的所有可能值后，才开始重复

- 约束块`constraint`，限制随机范围

- `randomize()`函数：SV内置函数，成功返回1，失败返回0

- `$fatal`函数：随机化失败，仿真立即停止并报错

  第一个参数为0，代表不打印任何多余的仿真信息，只显示你自定义的字符串。

```verilog
class Packet;
    // 随机变量
    rand  bit [31:0] src, dst, data[8];
    randc bit [7:0]  kind;

    // src 的约束
    constraint c { src > 10;
                   src < 15; }
endclass

Packet p;

initial begin
    p = new(); // 产生一个包
    // 随机化并检查结果
    assert (p.randomize())
    	else $fatal(0, "Packet::randomize failed");
    
    transmit(p);
end
```



注意：

- 不能在构造函数中随机化对象；
- 尽量不要随机化有符号变量



# 3. 约束

- 对于没有随机变量的约束

  randomize()只会检查值是否在约束定义范围内。

  在范围内，返回1；不在则返回0



受约束的随机类

- 条件约束
- `inside`运算符

```verilog
class Stim;
    const bit [31:0] CONGEST_ADDR = 42; //只读常量，例化后不能修改值
    typedef enum {READ, WRITE, CONTROL} stim_e;
    randc stim_e kind;      // 枚举变量
    rand  bit [31:0] len, src, dst;
    bit congestion_test;

    constraint c_stim {
        len < 1000;
        len > 0;
        
        if (congestion_test) {
            dst inside { [CONGEST_ADDR-100 : CONGEST_ADDR+100] };
            src == CONGEST_ADDR;
        }
        else
            src inside { 0, [2:10], [100:107] };
    }
endclass
```



## 排序约束

不正确的排序约束：

```verilog
class order;
    rand bit [7:0] lo, med, hi;
    constraint bad { lo < med < hi; } // 错误！
endclass
```

仿真器计算步骤：

- 计算 `(lo < med)`。这个表达式的结果是一个 **1 bit 的布尔值**（如果为真则返回 `1'b1`，为假则返回 `1'b0`）。
- 将这个 **1 bit 的结果**（0 或 1）与 `hi` 进行比较，即 `(0 or 1) < hi`。



正确写法：

```verilog
class order;
    rand bit [7:0] lo, med, hi;
    constraint good {
        lo < med;
        med < hi;
    }
endclass
```



## 权重分布

关键词：`dist`

- `:=`：每个值的权重相同
- `/=`：权重均分

```verilog
rand int src, dst;
constraint c_dist {
    // 使用 := 操作符：每个值分配相同的权重
    src dist { 0 := 40, [1:3] := 60 };
    
    // 使用 :/ 操作符：权重均分到范围内的每个值
    dst dist { 0 :/ 40, [1:3] :/ 60 };
}
```



## 随机约束取反

```verilog
rand int c;
int lo,hi;
constraint c_range{
    !(c inside {[lo:hi]}); // c<lo或c>hi
}
```



## 使用数组集合进行约束

 使用数组的随机集合约束：

- 数组集合中每个值的取出概率相等

```verilog
rand int f;
int fib[5]='{1,2,3,5,8};
constraint c_fib{
    f inside fib;
}
```



打印数组中各种值的分布：

- 数组内置方法max()：返回一个队列，因为最大值可能不只有1个；
- 直方图打印逻辑：通过计算 `count[i]` 占 `maxx[0]` 的比例来控制打印星号的数量；

```verilog
class Weighted;
    rand int val;
    // 数组中 8 出现了 5 次，其他数字出现次数较少
    int array[] = '{1, 1, 2, 3, 5, 8, 8, 8, 8, 8}; 
    constraint c { val inside array; }
endclass

Weighted w;

initial begin
    int count[9], maxx[$];
    w = new();

    repeat (2000) begin
        assert(w.randomize());
        count[w.val]++; // 统计值出现的个数
    end

    maxx = count.max(); // 获取统计结果中的最大值（返回一个队列）

    // 输出值的分布（打印简易直方图）
    foreach (count[i]) begin
        if (count[i]) begin
            $write("count[%0d]=%5d ", i, count[i]);
            // 根据比例打印星号 (*)
            repeat (count[i] * 40 / maxx[0]) $write("*");
            $display;
        end
    end
end
```



使用队列进行随机约束：

- 使用队列进行动态随机约束；
- 枚举类型的`name`方法：返回该枚举值的字符串名称

```verilog
class Days;
    typedef enum {SUN, MON, TUE, WED, THU, FRI, SAT} days_e;
    
    days_e choices[$];           // 声明一个枚举类型的队列，用于存放备选项
    rand days_e choice;          // 待随机的变量
    
    // 约束变量 choice 必须在队列 choices 包含的范围内
    constraint cday { choice inside choices; }
endclass

initial begin
    Days days;
    days = new();

    // 场景 1：只在周末中随机
    days.choices = {Days::SUN, Days::SAT};
    assert (days.randomize());
    $display("Random weekend day %s\n", days.choice.name);

    // 场景 2：只在工作日中随机
    days.choices = {Days::MON, Days::TUE, Days::WED, Days::THU, Days::FRI};
    assert (days.randomize());
    $display("Random week day %s", days.choice.name);
end
```





## 条件约束

SV中两种条件约束方式：

- 蕴含操作符`->`

  ```verilog
  (io_space_mode) -> addr[31] == 1'b1;
  ```

  条件不满足时，不产生任何约束；

  - 蕴含操作符不会“保护”它的条件

    如果 `io_space_mode` 本身也是一个 `rand` 变量，随机化求解器可能会为了满足 `addr[31] == 1'b1` 这个结果，反过来倒推让 `io_space_mode` 变成真，或者为了不满足它而让 `io_space_mode` 变成假。

    这种“双向影响”是 SystemVerilog 约束求解器的特性，在使用这两者时都要注意。

  

- `if-else`结构

  ```verilog
  constraint c_len_rw {
      if (op == READ)
          len inside {[BYTE:LWRD]};
      else
          len == LWRD;
  }
  ```



# 4. 约束块控制

## 约束块开关控制：`constraint_mode()`

- **`constraint_mode(0)`**：禁用约束
- **`constraint_mode(1)`**：启用约束

```verilog
class Packet;
    rand int length;
    constraint c_short { length inside {[1:32]}; }
    constraint c_long  { length inside {[1000:1023]}; }
endclass

initial begin
    p = new();
    // 1. 产生长包：禁止短包约束
    p.c_short.constraint_mode(0); // 关闭 c_short
    assert(p.randomize());        // 此时只有 c_long 生效
    transmit(p);

    // 2. 产生短包：禁止所有约束，再单独使能短包约束
    p.constraint_mode(0);         // 关闭类中所有约束
    p.c_short.constraint_mode(1); // 重新开启 c_short
    assert(p.randomize());        // 此时只有 c_short 生效
    transmit(p);
end
```





## 内嵌约束randomize() with

关键词：`randomize() with`

```verilog
class Transaction;
    rand bit [31:0] addr, data;
    // 类内部的固定约束
    constraint c1 { addr inside {[0:100], [1000:2000]}; }
endclass

Transaction t;

initial begin
    t = new();

    // 1. 使用 inline 约束缩小范围：addr 范围变为 50-100 或 1000-1500，且 data < 10
    assert(t.randomize() with { addr >= 50; addr <= 1500;
                               data < 10; });
    driveBus(t);

    // 2. 强制 addr 取固定值 2000，且 data > 10
    assert(t.randomize() with { addr == 2000; data > 10; });
    driveBus(t);
end
```



## 约束变量开关：`rand_mode()`

- 每个被声明为 `rand` 的变量都有一个内置的 `rand_mode()` 方法。
  - **`variable.rand_mode(0)`**：禁止随机化（变为非随机）。
  - **`variable.rand_mode(1)`**：使能随机化。



- 随机变量禁止随机的方式

```verilog
class Packet;
    rand bit [31:0] addr, data;
endclass

// 方式1：
initial begin
    Packet p = new();
    p.addr.rand_mode(0); // 关闭 addr 的随机化
    
    // 此时只有 data 会变，addr 保持其初始值或上次随机的值
    assert(p.randomize()); 
end

//方式2：
initial begin
    p = new();
    // 只有 data 会随机化，addr 被“非随机化”了
    assert(p.randomize(data)); 
end

//方式3：
initial begin
    // 通过内联约束让 addr 失去随机变化的余地
    assert(p.randomize() with { addr == 32'hAAAA_BBBB; }); 
end
```
